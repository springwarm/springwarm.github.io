跨端 Markdown 笔记本

你的笔记，不该认主人。

纯 Markdown，只住你自己的 Git 仓库。零服务端、零订阅、零第三方追踪。客户端直连你选择的 Git 托管平台。

下载 MarkNote 看看它如何工作

为什么需要逃离

你写下的内容，真的属于你吗？

很多笔记工具把内容锁进私有格式和对方的云。迁出困难，订阅一停，同步就断。

私有格式

笔记打不开，换工具先要过一遍导出迷宫。

订阅绑定

免费额度收紧后，跨设备同步往往变成付费门槛。

迁移成本

服务调整或停运时，几年积累会变成一场冒险。

跨端割裂

桌面功能齐，手机却残缺；同一份笔记两套体验。

品牌立场

所以，我们选择不寄人篱下。

MarkNote 起源于一次逃离：作者长期把笔记锁在厂商私有格式与云端，订阅越来越贵，想迁走却无从下手。 品牌是一匹狼，因为狼不认主人——你的笔记也不该认。

MarkNote 不经营你的数据，也不另起一套账号体系。它是纯客户端，连接你的设备和你自己的 Git 托管仓库。

三根支柱

巢穴、牵绳、回家的路

自己的巢穴

数据主权：笔记是纯 .md，只存你自己的 Git 仓库。

随时 git clone，用任意编辑器打开。没有厂商私有格式，就没有锁定。

没有牵绳

自由：零自建服务端、零订阅、零第三方追踪。

Git 凭据与 AI Key 只存本机系统钥匙串，不进仓库、设置文件或日志。

认得回家的路

不丢：断网先写本地，联网后自动补推。

冲突保留副本，删除先进回收站。数据不丢是硬红线。

产品证据

打开仓库，就是全部真相。

停用 MarkNote 之后，笔记正文仍是普通 Markdown。本页托管仓和更新分发仓只负责宣传与安装包，不是你的笔记存储位置。 

your-repository/
├── notes/                 # 人类可读的 .md 正文
│   ├── 01932f4e-8b2a-7c3d-9e1f-2a4b6c8d0e1f.md
│   └── work/
│       └── 01932f4f-1c90-7a11-8d22-3b5c7d9e0f2a.md
├── assets/                # 图片与附件
└── .marknote/             # 配置 / 回收站 / 冲突副本 / 可重建索引
    ├── config.json
    ├── tags-index.json
    ├── trash/
    ├── conflict/
    └── index/
  • notes/ 是正文 只放人类可读的纯 Markdown 与 front-matter；新建用 UUIDv7 文件名，标题写在首行 H1。
  • .marknote/ 不是正文仓 放配置、回收站、冲突副本和可重建索引（含 tags-index）；丢失可从笔记重建。
  • Git 历史可追溯 提交记录跟着仓库走；换设备只要 clone / pull。

使用场景

写下来，带走，再取回。

1. 写下

所见即所得编辑 Markdown，保存后进入你的 Git 仓库。

2. 继续

另一台设备登录同一仓库，pull 后接着写。断网也能先落本地。

3. 取回

任何时候用 git 或其他编辑器打开同一份 .md，不依赖 MarkNote。
